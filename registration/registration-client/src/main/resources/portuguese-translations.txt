# Portuguese translations used to translate text fields between English (eng) and Portuguese (por).
# Fields to translate are configured with mosip.registration.transliteration.fields (default: addressLine1,addressLine2,addressLine3).
#
# Format (one entry per line, file is UTF-8):
#   english = portuguese    translate both ways
#   english > portuguese    only English -> Portuguese
#   english < portuguese    only Portuguese -> English
#   english >               English word is dropped when translating to Portuguese
#   ! phrase                never translate this phrase (place names), both directions
#
# - Matching ignores case. Portuguese matching also ignores accents, so "praca" matches "praça".
# - Multi word entries ("next to = ao lado de") are matched before single words.
# - When a word appears in more than one entry, the FIRST entry wins for that direction,
#   so keep the preferred translation first.
# - Words not listed here (street names, place names, people's names) are copied as they are.
#   Accents are removed from them when translating Portuguese -> English.
# - Translation is word for word: word order is not changed ("Main Street" -> "Principal Rua").
